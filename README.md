# 模型选择器

将 Codex 模型菜单按前缀整理成两级分类，并根据内容自动调整菜单宽度。

## 功能

- 按模型名称前缀生成一级分类
- 在二级菜单中保留具体模型选择
- 同时兼容旧版模型子菜单和新版 `simple / advanced` 模型选择器
- 选择模型后自动让出原生思考等级视图，并保留其键盘交互
- 两级模型名始终完整显示，悬浮时平滑展开渠道前缀
- 根据标签长度调整菜单宽度并保持原生选择行为

## 安装

将本目录作为本地功能包安装，或在独立 Git 仓库发布后从 Codex Tweaks 的功能包页面安装。首次安装后需检查依赖、完成编译并手动启用。

## 权限与安全

- Renderer：读取和重排 Codex 模型选择菜单
- Node：未使用
- 网络：不直接发起网络请求

## 兼容性

- Codex Tweaks API：v3
- 已测试平台：macOS
- 已知限制：依赖 Codex 模型菜单的当前 DOM 和交互结构

## 开发

运行 `npm install` 安装锁定依赖，通过 `mise run check` 检查 Renderer 入口，然后在 Codex Tweaks 中重新编译并验证菜单打开、分类切换、模型选择和停用清理。
